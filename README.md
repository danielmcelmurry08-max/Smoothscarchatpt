# SmoothScar provider campaign

Responsive BioRNA clinical-evidence landing page with linked campaign creatives and provider inquiry forms.

## Build

Run `npm test` then `npm run build`. No dependencies required. Publish directory: `dist`. Production branch: `main`.

## Netlify

Connect to the existing smoothscar project. Enable form detection, configure provider-access and provider-feedback notifications to providers@smoothscar.com, customer-quotes and customer-feedback to contact@smoothscar.com, and smooth-skin-webinar to info@smoothscar.com after verifying recipient eligibility, and leave provider-test notifications disabled. Resume auto publishing when ready to deploy this source.

The `.netlify` directory is ignored and must not be committed. Netlify Forms supports CSV export for Excel. Notifications are not configured by source alone. A successful form HTTP response does not confirm inbox delivery.

## Evidence

Generated imagery is illustrative. Research identifies the studied siRNA intervention and dermatologic population and does not establish TKA/THA outcomes for marketed formulations.
